# Libft

## Description

Libft is a custom C library developed as part of the 42 Common Core curriculum.

The goal of this project is to recreate a set of functions from the standard C library and implement additional utility functions from scratch. The project focuses on developing a better understanding of C programming fundamentals, including memory management, pointers, strings, arrays, type conversion, file descriptors, and linked lists.

The final result is a reusable static library called `libft.a`, which can be used in future 42 projects.

The project is divided into three main parts:

* **Part 1:** Reimplementation of standard C library functions.
* **Part 2:** Additional functions for strings, memory allocation, conversion, and file descriptors.
* **Part 3:** Functions for creating and manipulating linked lists.

## Instructions

### Compilation

The project includes a `Makefile` for compiling the library.

To compile the library:

```bash
make
```

This creates the static library:

```text
libft.a
```

To remove the generated object files:

```bash
make clean
```

To remove the object files and the library:

```bash
make fclean
```

To rebuild the library from scratch:

```bash
make re
```

### Using the Library

Include the library header in your C program:

```c
#include "libft.h"
```

Compile your program together with `libft.a`:

```bash
cc main.c -L. -lft
```

The resulting executable can then be run normally.

## Technical Choices

The project is written in **C** and compiled using `cc`.

The library is built as a **static library** named `libft.a` using the provided `Makefile`.

The implementation follows the constraints of the 42 Libft project and focuses on manual memory management, pointer manipulation, string handling, and linked-list operations.

Particular attention was given to:

* Dynamic memory allocation and proper use of `free`.
* Pointer manipulation and pointer-to-pointer usage.
* Correct string termination using `'\0'`.
* Handling edge cases such as empty strings and boundary integer values.
* Memory management when working with linked lists.
* Following the 42 Norm coding standard.
